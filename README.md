# Nginx Log Analyser (in progress)

This is a simple Bash script project to practice basic log analysis and Linux command-line skills.  
It will analyze an Nginx access log and output:
- Top 5 IP addresses
- Top 5 requested paths
- Top 5 status codes
- Top 5 user agents
